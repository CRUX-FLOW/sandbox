## Description

# Sub-task — Description

A step under a Task. The harness uses it to check how each tracker handles a child of a Task.

## Structure

# Sub-task — Ticket Structure

A Sub-task has a title and a one-line description. The mcp-verify harness creates these as test data
under its run parent; nothing else is required of them.
